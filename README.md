======================================
 YP3Convert.sh - HOW TO USE
======================================

1. Dependencies:
   Ensure 'ffmpeg' is installed on your Linux system.

2. Setup Permissions:
   chmod +x YP3Convert.sh

3. Run the Tool:
   ./YP3Convert.sh <path_to_video.mp4>

The script will automatically scale, rotate, flip, and 
slice your video into 170-second MJPEG .avi chunks 
inside a folder named after your file.
